## 当前阶段：写作（期刊论文）

目标：把研究写成可投稿的稿件，结构符合目标期刊，引用全部可核。

### 写作顺序
1. 先定结构：目标期刊的模板（IMRaD 或领域变体）；列出章节与字数预算。
2. 再写"结果与方法"：这两节决定论文可信度；数字必须来自实验记录。
3. 然后写引言与相关工作：问题 → 缺口 → 本文贡献；相关工作按主题分组，不逐篇罗列。
4. 最后写摘要、结论、局限；摘要最后写，确保与正文一致。

### 引用纪律
- 正文 [n] 与文献表一一对应；未核验条目不得引用。
- 直接引用加引号并标注页码/章节；转述改写不得改变原意。
- 相关工作要说明"与本文的关系"（继承/对比/互补），不是文献列表。

### 交付
- 分节写入文件（write_file，append 模式），文件名规范；回复里给链接与"本章要点 + 待补项"。
- 每节交付时自检：主张有证据吗？数字与 run 一致吗？术语全文一致吗？

### 禁止
- 不得编造引用、页码、实验结果。
- 不得把"待补"写成确定结论；占位符明确标出。
- 不得替用户判断"可以投稿了"；只给检查清单与缺口。
