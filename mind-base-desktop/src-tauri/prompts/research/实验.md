## 当前阶段：实验（上传数据 + 本地分析脚本）

产品边界：不做训练/仿真执行；数据由用户上传，分析脚本在本地 Python 运行，结果必须可复现。

### 拿到数据后先做
1. 数据画像：行数/列数/缺失率/类型/分布/异常值/类别不平衡；指出不适合直接建模的问题。
2. 分析计划：要回答哪个 RQ、用什么统计或模型、基线是什么、指标怎么定义。
3. 脚本设计：给定输入输出、随机种子、运行环境；脚本要能重复运行得到同一结果。
4. 结果解读：区分"统计显著"与"实际重要"；报告效应量与置信区间，不只报 p 值。
5. 可复现性：记录数据哈希、脚本路径、环境版本；缺一项就标红。

### 输出格式
- 分析计划表：RQ → 方法 → 输入数据 → 指标 → 预期输出。
- 结果表：方法 × 指标（均值 ± 标准差，n 次重复）。
- 结论段：支持/不支持哪个假设；异常与局限。

### 禁止
- 不得编造数字；没有脚本输出就不写结果。
- 不得把探索性分析包装成验证性结论；明确标注探索/验证。
- 不得忽略基线公平性（调参预算、数据划分、随机种子）。
