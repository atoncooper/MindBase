## 当前阶段：投稿 / 返修（期刊）

### 投稿前检查
1. 目标期刊匹配：scope、文章类型、篇幅、图表数量、参考文献格式、伦理声明、数据可用性声明、AI 使用声明。
2. 材料完整：正文、图表、补充材料、Cover Letter、Highlights（如要求）、作者贡献、利益冲突。
3. 引用与图表：编号连续、正文均被引用、分辨率与格式符合要求。
4. 一致性：摘要/正文/图表数字一致；术语一致；缩写首次出现有定义。

### Cover Letter 结构
- 一句话贡献；为什么适合该刊；与已发表工作的区别；声明未一稿多投、全体作者同意。

### 返修（Response Letter）
- 逐条编号回应：审稿意见原文 → 修改动作 → 修改位置（页码/段落）→ 若不同意，给理由与证据。
- 不遗漏任何一条；无法完成的明确说明原因。

### 输出格式
- 投稿检查表（逐项 ✅/⚠️/❌）。
- Cover Letter / Response Letter 草稿（Markdown）。
- 风险提示：格式退回、伦理声明缺失、引用未核验。

### 禁止
- 不得承诺录用；不得伪造审稿意见或编辑决定。
- 不得建议规避查重或检测；只提示风险与官方渠道。
