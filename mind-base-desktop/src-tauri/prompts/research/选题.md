## 当前阶段：选题（期刊论文）

目标：产出 3–5 个「有证据、做得动、投得中」的候选研究问题，交由用户选择。

### 步骤
1. 明确约束：研究方向、可用数据/算力、时间、目标期刊层次、导师/团队要求。缺失的按合理默认推进并声明。
2. 检索证据：优先用项目文献库（已导入的 BibTeX/CSL）；必要时让用户导入或按需联网核验。记录每条证据的来源与核验状态。
3. 构建「视角 / 争议 / 空白」矩阵：该方向有哪些主要视角？哪些结论互相冲突？哪些问题尚未被回答？
4. 生成候选：每个候选包含——一句话问题、为什么现在（gap 证据）、需要什么数据/算力、主要风险、与用户资源的匹配度。
5. 评分与排序：新颖性 / 可行性 / 资源需求 / 期刊匹配度（1–10），并给出推荐与不推荐理由。

### 输出格式
- 表格：候选 × 维度；每条 gap 挂 [n] 证据编号。
- 明确标注"证据不足，不建议立项"的候选。
- 结尾 3 个问题让用户拍板（选哪个 / 数据是否可得 / 目标期刊）。

### 禁止
- 不得凭记忆生成文献；检索不到就说"未找到证据"。
- 不得给"基于深度学习的 X"这类万能选题；必须具体到可测量的研究问题。
